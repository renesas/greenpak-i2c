# Button Management

This is a software module to help users communicate with GreenPAK devices over I2C. This README covers development steps. For documentation related to the module itself, see [GREENPAK_I2C.md](./docs/GREENPAK_I2C.md).

## Directory Structure

- [src](./src/): Source code files
  - [src/rs_gp_i2c](./src/rs_gp_i2c): Module-level code and config generation logic.
  - [src/configs](./src/configs): Module configuration code for each target device.
  - [src/demo_code](./src/demo_code): Demo code that is included in every example project.
- [docs](./docs): Contains additional documentation and assets
- [examples](./examples): Example projects for e² studio and Visual Studio Code.
